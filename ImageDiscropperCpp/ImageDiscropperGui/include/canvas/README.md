# include/canvas — 画布与图层对外声明

**目录作用**：GUI **画布层**的公共头，声明基于 QGraphicsView/Scene 的图层化画布：底图、遮罩、网格线、
切割线、选区框、L3 单元点选交互图元与标注矢量叠加图元。本目录只放**类声明边界**；实现与详尽渲染 / 交互说明见
[src/canvas/](../../src/canvas/README.md)。

**分块依据**：按 **z 序图层化**拆分——每类图层 / 交互图元一个头，互不耦合；六类图层/图元头（mask/grid/grid_handle/cell_picker/selection_rect/annotation/image_layer + z_order）位于 `items/` 子目录（清单见 [items/README.md](items/README.md)），本层只留场景/视图/模式/输入适配器声明；场景坐标统一为
**原图像素坐标**。交互按**输入适配器分层**：设备语义（鼠标键 / 滚轮 / 右键菜单；触控合成序列 / 捏合手势 / 双击）
隔离在 `ICanvasInputAdapter`，`CanvasView` 只暴露与设备无关的业务手势执行面（`gesture*`）。
本目录**只渲染 Core 给出的结果**（切割线来自 `generateCutLines`、保留块来自 `EngineResult.kept`、
网格来自 `Grid`），不含任何几何计算。

> 命名空间统一 `idc::gui`。选区与 L2 多矩形的移动·缩放·拖边统一经 `SelectionRectItem::rectChanged` →
> `CanvasScene::selectionEdited` / `multiRectEdited` 转发到 `CanvasCoordinator` 写回 `Document`；拖拽期跳过面板回同步与对正在拖图元的回设（避免抖动 / 自删崩溃）。
> L2 多矩形**重叠区的按下归属不靠 z 序自动抓取**（各框同 z，否则被压住的旧矩形点不到）：场景按命中栈路由 + 同点连击下探，
> 选中的下标另经 `CanvasScene::multiRectSelectionRequested` → `CanvasCoordinator` → `ParamPanel::selectRectRow` 回灌列表行与坐标框
> （列表行反过来经 `rectSelected` → `setActiveMultiRect` 成为下一次按下的路由基准，故「列表选中后可直接拖该框」），口径见 SPEC §8.2。
> 该路由靠图元自抓（`grabMouse`），而基类释放只自动解除隐式抓取，故释放分支送达后须 `releasePressGrab()` 归还。
