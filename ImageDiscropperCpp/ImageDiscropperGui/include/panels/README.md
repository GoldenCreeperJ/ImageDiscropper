# include/panels — 模式、图层、预处理、参数、导出与标注面板对外声明

**目录作用**：GUI **面板层**的公共头，声明左侧模式/极性、交互模式、图层显隐三面板与右侧图层编辑（「图片」节）、预处理、参数、导出、标注属性五面板共八个 `QWidget`（另含右侧折叠容器 `AccordionPanel`，承载图片/预处理/标注/参数/导出五节、多节可同开，非功能面板）。
本目录只放**类声明边界**；实现与详尽控件 / 信号说明见 [src/panels/](../../src/panels/README.md)。

**分块依据**：各面板均**不直接调 Core 几何/光栅化**。模式/参数/导出面板读写 `Document`（用户操作 → 写回 `Document` →
`Document` 发 `changed()` → app 层 `PreviewController` 刷新预览；反向同步用 `blockSignals` 防回环）；预处理面板是**声明式预处理队列编辑器**，
只发队列意图信号（stepAppend/Replace/Remove/Move/reset），由 `PreprocessController` 经 `EngineBridge` 调 Core 从原图重放物化工作图；标注工具/图层/属性面板同样只发意图信号，
由 `AnnotationCoordinator` 写回 `AnnotationBridge`（其内部调 Core annotation/geometry）。按关注点各成一文件。

> `pattern_form`/`placement_row`（新建画布对话框的采参组件，非面板）位于 `app/forms/`，与 `NewCanvasDialog` 同域。

| `export_panel.h`          | `ExportPanel`（`QWidget`）         | 右侧「导出」页：输出模式 / 目录 / 文件 / 格式 / 质量 / 命名 / 填充色（`padRow_`，恒可见；合并底色 / Pad 补白 / 有损压平）+ 合并重排（自动 cols·rows、双警告；块尺寸不全等时按准入门限回退坍缩/分离）+ 导出时烧录标注开关（`burnInChanged`/`setBurnInChecked`）+ 导出按钮；**输出图像预览缩略图**：`setPreviewPixmap` 显示由 `PreviewController` 按 Core `Composition` 渲染的低分辨率预览（与文字信息 `setPreviewInfo` 并存）；重排单元宽/高为坐标框，另收 `50%` 百分比（基准画布，`0%`=自动）                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `preprocess_panel.h`      | `PreprocessPanel`（`QWidget`）     | 右侧「预处理」页：**声明式预处理队列编辑器**，轻操作分**几何/色彩两个独立列表**（几何＝旋转/翻转，色彩＝黑白/色道反色/色道分离，反色与分离共用 R/G/B 通道选择），各自带类型选择 + 参数区 + 列表（添加/更新所选/删除/上移/下移）；顶部「画布尺寸」为独立常驻区（按比例缩放/目标尺寸，不入队列）；底部重置；两列表映射到单一底层队列（几何行＝扁平下标、色彩行＝几何行数 + 色彩行号），发 `stepAppendRequested`/`stepReplaceRequested`/`stepRemoveRequested`/`stepMoveRequested`/`resetRequested` 队列意图信号（不持真相）。**按目标驱动**（多层画布，SPEC §8.2）：顶部 `targetLabel_` 显式标注当前预处理目标（选中图片图层＝「图片图层 #id」，否则＝「画布」），队列编辑经 `PreprocessController::commitActive` 落到 `Document::activeSession()`（画布会话或选中层会话）；画布尺寸的目标宽/高为坐标框，另收 `50%` 百分比（基准当前工作图）                                                                                                                                                                                                                                                                                            |
| `mode_tool_panel.h`       | `ModeToolPanel`（`QWidget`）       | 左侧「交互模式」面板：顶部四态互斥模式（框选 / 图片拾取 / 标注选取 / 标注绘制，`QButtonGroup`，发 `modeChanged(CanvasMode)`），仅「标注绘制」态展开形状子行（各形状 + 多线段 + 文字 + 画笔互斥按钮组，发 `toolSelected(AnnoTool)`）                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `layer_panel.h`           | `LayerPanel`（`QWidget`）          | 左侧「图层」组：底图/图片图层/标注/遮罩/网格线与切割线（同一开关）/选取边框/单元编号显示开关（按 z 序；一行一开关；标注烧录开关属导出面板；**底图开关（`baseVisibilityChanged`）仅切换画布预览图元、不改导出合成**），发 `baseVisibilityChanged`/`imageLayerVisibilityChanged`/`annotationVisibilityChanged`/`maskVisibilityChanged`/`gridVisibilityChanged`/`selectionVisibilityChanged`/`numberVisibilityChanged`（网格线与切割线共用 `gridVisibilityChanged`：L3 为网格线、L1/L2 为贯穿切割线，两模式互斥故无重叠）；**图片图层为一个整体开关**（非逐子项）：`imageLayerVisibilityChanged` 经 `Document::setImageLayersVisible` 落到 `Document::imageLayersVisible_` 运行态单开关（不入配置；发 `imageLayersVisibleChanged` 纯切换预览图层像素与落位框可见性、不重组工作图也不影响导出，行常驻可用）；`setMaskVisible` 供外部切换遮罩时反向同步                                                                                                                                                                                                        |
| `layer_edit_panel.h`      | `LayerEditPanel`（`QWidget`）      | 右侧「图片」页（**多层画布**，SPEC §8.2）：作用于画布当前拾取层（`selectedLayerId`，无内置图层列表）的上/下移一层·置顶/置底·删除·清空、**添加图片图层**（复用 `NewCanvasDialog` 采参：未勾附加图→程序图案产 `recipe` 层 / 勾选附加图→对话框两段合成的整幅结果作 `file` 层、落位恒等；不撑大）、落位 `transform` 编辑（画布锚点 + 图片枢轴各 9 向 + 自由 x/y + 目标宽高 + 不透明度）、改画布尺寸（仅清框选）。只发意图信号（`layerMoveRequested`/`layerMoveEdgeRequested`/`layerRemoveRequested`/`layerTransformRequested`/`baseOpacityRequested`/`canvasOpacityRequested`/`canvasSizeRequested`/`addImageRequested`/`clearAllLayersRequested`），由 `SessionController` 落 `Document` 声明态 CRUD→`layersChanged`→`PreprocessController::recomposeLayerCanvas` 重组。与 `LayerPanel`（画布叠加图层显示开关）职责不同；落位偏移与目标宽高为坐标框，另收 `50%` 百分比（基准画布）                                                                                                                                                                      |
| `annotation_prop_panel.h` | `AnnotationPropPanel`（`QWidget`） | 右侧「标注」属性页：边框色选择器（含 alpha）/ **独立填充色选择器** / 描边粗细 / 填充开关 / **转角圆角半径** / 文字内容 / 字号，发 `colorPicked`/`fillColorPicked`/`strokeChanged`/`fillChanged`/`cornerRadiusChanged`/`textChanged`/`fontSizeChanged`；不可填充的形状（直线 / 文字）或未勾选填充时填充色控件置灰，无转角形状（直线 / 圆 / 椭圆 / 文字）时圆角控件置灰；另含叠放区（上移一层 / 下移一层 / 置于顶层 / 置于底层，仅选中标注时可用，发 `stackRaiseRequested`/`stackLowerRequested`/`stackToFrontRequested`/`stackBackRequested`，由 `AnnotationCoordinator` 转 AnnotationBridge → Core `moveAnnotation`）；又含变换区（缩放%/旋转° 显示选中形状的**绝对累积变换**、含负=翻转，**无应用按钮、改动即生效**）发 `transformApplyRequested`（每个 spin 按**单轴**把目标绝对值换算为相对基准的增量下发，仅选中标注时可用；**不回弹**、靠 `changed`→`syncFromModel` 回显）；`setTransformPreview` 供画布 OBB 手柄拖拽时把**绝对**缩放/旋转逐帧回显到数值（与手柄联动）；翻转无按钮，由画布手柄拖过对边（负缩放）实现；页尾另有「删除选中标注」（发 `deleteSelectedRequested`，仅选中时可用，与标注菜单/Delete 键同一入口）与「清除全部标注」（发 `clearAllRequested`） |
| `accordion_panel.h`       | `AccordionPanel`（`QWidget`）      | 右侧「折叠面板」**容器**（非八个功能面板之一）：多节竖排、每节一条标题按钮 + 内容 widget（`addSection` reparent 内容、初始展开），**多节可同时展开**（区别于 `QToolBox` 互斥单节），整体置外层 `QScrollArea` 滚动触达；`isSectionExpanded`/`expandSection`/`retitle` 供 `PreviewController`「导出页可见才渲染」判定与语言热切换重放，`sectionToggled` 交外部联动。移动端抽屉不用本容器（另以 `QStackedWidget` 页区 + 横向按钮条）                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |

> 命名空间统一 `idc::gui`。面板不实现几何 / 切割；L2 多矩形并集、L3 网格行列推导等全部由 Core 完成。
