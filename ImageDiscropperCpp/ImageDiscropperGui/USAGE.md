# ImageDiscropper GUI 使用说明

> 面向最终用户的操作手册（对应 guideline §7.1 / 交付物 D-2）。
> 设计维护者请改读同目录 [`DESIGN.md`](DESIGN.md)（§7.2 设计说明文档）。

ImageDiscropper 回答的不是「保留哪一块」，而是「**沿哪些线切开、留下哪些块、怎么重新拼起来**」。
所有功能都建立在统一的 **Grid-Selection-Emit 模型**之上：

```
原图 → ① 切割线集合 → ② 诱导网格 → ③ 选择集 → ④ 极性(保留/删除) → ⑤ 排布导出(分离/坍缩/重排)
```

三种模式（L1/L2/L3）共用同一条引擎路径，只是参数预设不同。

## 1. 安装与启动

### 1.1 构建前置

- **CLion**（或命令行 CMake ≥ 3.16）+ 支持 C++17 的编译器（MSVC / MinGW / Clang）。
- **vcpkg**（classic 模式），且已安装 `qtbase`（Qt 6.x）。仓库不含 `vcpkg.json` / `CMakePresets.json`。

### 1.2 构建命令

以**仓库根**为 CMake 源：

```bash
cmake -S . -B build -DCMAKE_TOOLCHAIN_FILE=<vcpkg>/scripts/buildsystems/vcpkg.cmake
cmake --build build --target idc_gui
```

生成的可执行文件为 `idc_gui`。

> **Windows 运行提示**：若启动报缺 `qwindowsd.dll` 等 Qt 平台插件，需把 vcpkg 安装的 Qt
> `bin` 目录（含 `platforms/`）加入 `PATH`，或用 `windeployqt` 就部署插件目录。

### 1.3 启动

- 直接运行 `idc_gui`；
- 或带图启动：`idc_gui path/to/image.png`（首个位置参数为图像路径时自动打开）。

首次进入默认 **L1 标准提取模式**，并弹出一次性引导说明三种模式的区别。

## 2. 界面概览

主窗口采用「菜单栏 + 工具栏 + 左中右三栏 + 状态栏」的经典图像工具布局（`QSplitter` 水平三分）：

```
┌───────────────────────────────────────────────────────────────┐
│ 菜单栏：文件 / 编辑 / 图像 / 标注 / 视图 / 帮助                    │
├───────────────────────────────────────────────────────────────┤
│ 工具栏：打开 导出 | 撤销 重做 | 放大 缩小 适应 | 模式切换(L1/L2/L3) │
├──────────┬────────────────────────────────┬───────────────────┤
│ 左侧面板  │         中央画布                │   右侧面板         │
│ (约220px)│      (QGraphicsView)           │  (约300px, 选项卡) │
│ ·模式切换 │                                │  ·参数页           │
│ ·极性开关 │   底图 + 遮罩 + 切割线 +        │  ·导出页           │
│ ·标注工具 │   选区 + 网格 + 标注 + 编号      │  ·图像页           │
│ ·图层列表 │                                │  ·标注页           │
├──────────┴────────────────────────────────┴───────────────────┤
│ 状态栏：坐标 | 像素RGB | 当前模式 | 保留块数 | 缩放 | 提示信息      │
└───────────────────────────────────────────────────────────────┘
```

- **左侧面板**（可滚动）：模式切换（L1/L2/L3）、极性开关（保留/删除）、标注工具面板、图层面板。
- **中央画布**：可缩放、可平移，占据最大空间。所有叠加图层见 [`DESIGN.md`](DESIGN.md) 的 z 序表。
- **右侧面板**（`QTabWidget`，四页）：**参数页**（随模式变化）、**导出页**、**图像页**（预处理）、**标注页**（标注属性）。
- **状态栏**：实时显示光标坐标、光标处像素 RGB、当前模式、保留块数、缩放倍数与提示/错误信息（错误为非模态，限时显示，不打断操作）。

### 画布视觉规范（配色）

| 元素 | 颜色 | 含义 |
| ---- | ---- | ---- |
| 画布背景 | 深灰 `rgb(45,45,45)` | 图像以外的空白区 |
| 保留块遮罩 | 绿色半透明 `rgba(0,200,0,60)` | 将被保留的区域 |
| 删除块遮罩 | 红色半透明 `rgba(200,0,0,60)` | 将被删除的区域 |
| 切割线 / 选区边框 | 橙色 `rgb(255,140,0)`（高亮 `rgb(255,90,0)`） | 贯穿全图的直线；切割线即选区边的延伸 |
| 网格线（L3） | 灰色 `rgb(150,150,150)` 虚线 | Core 诱导网格 |
| 标注选中高亮 | 蓝色 `rgb(0,160,230)` | 选中标注的 OBB 手柄 |
| 单元编号角标（L3 自定义序） | 黑底白字 | 每个已选单元左上角的 1-based 序号 |

## 3. 基础图像处理（预处理）

预处理在**切割之前**执行，作用于「工作图」；**原图始终保留**，可随时「重置预处理」还原。
入口：**图像菜单** 或 右侧 **图像页**（二者共用同一批操作）。

| 操作 | 说明 |
| ---- | ---- |
| 旋转 | 左转 90° / 右转 90° / 180°（步进按钮） |
| 翻转 | 水平翻转 / 垂直翻转 |
| 缩放 | 按比例（%）或按目标宽/高，可勾选「保持宽高比」 |
| 图像尺寸 | 直接指定目标宽/高重采样 |
| 黑白 | 转灰度 |
| 反色 | 对勾选的 R/G/B 通道取反（图像菜单「反色」默认全通道） |
| 色道分离 | 仅保留勾选的 R/G/B 通道 |
| 重置预处理 | 把工作图还原为原图 |

> **注意**：旋转 90°/270° 或缩放会改变图像尺寸，此时**基于旧尺寸的选区会被自动清除**，需重新框选。
> 大图缩放/重采样可能耗时，期间会弹出「处理中」进度对话框（不可取消），完成后自动关闭。
>
> **已知取舍**：预处理**不纳入 Ctrl+Z 全局撤销**（全局撤销只覆盖切割参数态），如需回退请用「重置预处理」。

## 4. 标注工具

标注是**独立矢量图层**，叠加在底图之上、**不改底图像素**；只有导出时勾选「烧录」才会合成进像素。

### 4.1 添加标注

1. 在左侧 **标注工具面板** 选择工具（见下表）。
2. 在画布上拖拽/单击绘制：
   - **两点形状**（矩形、正方形、圆、椭圆等）：按下拖拽实时预览，松手提交。
   - **多线段 / 画笔**：连续单击追加顶点 / 按住拖动绘制自由路径，按 **Esc** 或切换工具收笔。
   - **文字**：单击落点，弹出输入框填写文本后添加。

| 工具 | 绘制方式 |
| ---- | ---- |
| 选择/移动 | 选择并拖动已有标注（`Delete` 删除，`Ctrl+Z/Y` 撤销重做） |
| 矩形 / 正方形 | 两点拖拽 |
| 菱形 | 起点为中心，拖拽绘制 |
| 圆形 | 起点为圆心，两点距离为半径 |
| 椭圆 | 两点确定外接矩形 |
| 圆角矩形 | 两点拖拽 |
| 等腰 / 等边 / 直角 / 等腰直角三角形 | 按各自规则拖拽 |
| 直线 | 两点拖拽 |
| 多线段 | 连续单击追加顶点，Esc 收笔 |
| 文字 | 单击落点后输入 |
| 画笔 | 按住拖动绘制自由路径，Esc 收笔 |

### 4.2 编辑标注属性

选中标注后，右侧 **标注页** 可设置：**颜色、粗细、填充、文字内容、字号**，以及 **OBB 变换**（带符号缩放 X/Y、旋转角度，改动即生效、无「应用」按钮）。
画布上选中标注会出现 **8 个缩放手柄 + 1 个旋转手柄**（定向包围盒 OBB），拖拽即做缩放/拉伸/旋转/翻转（拖手柄越过对边＝翻转）。

### 4.3 标注菜单

`标注` 菜单提供：撤销标注 / 重做标注 / 删除选中 / 清除全部（二次确认）/ 标注属性定位。

> **已知限制**：当前标注类型**不含「箭头」与「扇形」**——底层 Core 的 `ShapeType` 尚未提供这两种类型（详见 [`DESIGN.md`](DESIGN.md) 的「已知限制」）。

## 5. 图层与烧录

左侧 **图层面板** 提供 6 个显隐开关（仅影响画布预览，不影响导出结果）：

| 图层 | 作用 |
| ---- | ---- |
| 底图 | 显示/隐藏预处理后的图像 |
| 遮罩 | 显示/隐藏保留(绿)/删除(红)预览遮罩 |
| 网格线 | 显示/隐藏 L3 网格与 L2 多矩形诱导网格 |
| 切割线 | 显示/隐藏贯穿全图的橙色切割线 |
| 选取边框 | 显示/隐藏橙色选区框与手柄（隐藏后选区不可编辑，需重新勾选） |
| 标注 | 显示/隐藏标注图层（隐藏后标注不可交互） |

**烧录开关**位于右侧 **导出页**（「导出时烧录标注」）：勾选后，导出时把标注按矢量合成进像素，标注会**随像素一起被切割**落位到各输出块。

## 6. 三种模式完整操作示例

### 模式区别与适用场景

| 模式 | 名称 | 定位 | 适用场景 |
| ---- | ---- | ---- | ---- |
| **L1** | 标准提取 | 默认，降低上手门槛 | 「我只想要这一块」——矩形/横带/竖带提取 |
| **L2** | 反向剔除 | 产品核心特色 | 「我要挖掉这一块，留下其余」——十字带剔除、多矩形并集剔除 |
| **L3** | 网格分割 | 高级编排 | 「把图切成网格，挑选单元并按序重拼」——图集/九宫格/切片重排 |

### 6.1 L1 标准提取示例

- **输入**：一张 1920×1080 的照片。
- **步骤**：
  1. 文件 → 打开图像（`Ctrl+O`）。
  2. 左侧模式选 **标准提取 (L1)**（或按 `1`）。
  3. 右侧参数页选形状：**矩形**（或横带/竖带），可直接填 `x1,y1,x2,y2`，或在画布上拖拽框选。
  4. 拖动选区四角手柄调整大小；方向键微调（±1px，`Shift`+方向键 ±10px）；靠近图像边缘/中心会自动吸附。
  5. 画布上绿色区即保留内容。
- **输出**：右侧导出页选「分离导出」+ 目标目录 + 格式（PNG），点导出（`Ctrl+S`）得到裁剪后的图。

### 6.2 L2 反向剔除示例

- **输入**：一张需要挖掉中部主体、保留四角的图。
- **步骤**：
  1. 打开图像，左侧模式选 **反向剔除 (L2)**（或按 `2`）。
  2. 右侧参数页选子功能：**十字**（或横线/竖线/多矩形）。
  3. 在画布拖拽出要剔除的矩形——橙色切割线**贯穿全图**，被删的十字带显示红色遮罩，保留的四角显示绿色遮罩。
  4. 用 **极性开关**（`K`/`R`）在 keep/remove 间切换，遮罩颜色与位置即时更新。
  5. 需剔除多个区域时选「多矩形」，逐个框选；删除区域为所有十字带的**并集**。
  6. 若想把当前矩形改成网格编辑，点参数页的「**转为网格模式编辑…**」（G-15）。
- **输出**：导出页选「合并坍缩」（剩余单元紧贴拼接）或「分离导出」，导出即得剔除后的结果。

### 6.3 L3 网格分割示例

- **输入**：一张图集，希望按网格切片、挑选部分单元并重排。
- **步骤**：
  1. 打开图像，左侧模式选 **网格分割 (L3)**（或按 `3`）。
  2. 右侧参数页填网格四元组 **`(x0, y0, cellWidth, cellHeight)`**，选择余量策略（丢弃/保留部分/填充）；网格线自动铺满全图，只读栏显示派生的行×列规模。
  3. 用**选择集**：单击选单元、画布框选、或「全选/反选/清空」。
  4. 设**排序**：行优先(row-major) / 列优先(column-major) / 自定义(custom)，可叠加 reverse（倒序）、snake（蛇形）；自定义序下可在画布拖拽单元调序，每个单元左上角显示序号角标。
  5. 导出页选「合并重排」，设置列/行（或点「按格数自动」依保留块数开方）、单元宽/高、填充色、填充顺序；参数不足时面板给出红字警告，导出前二次确认。
- **输出**：导出页点导出，得到按序重排拼合的新画布图像。

## 8. 导出参数说明

右侧 **导出页** 提供三种输出模式：

| 模式 | 说明 | 目标 |
| ---- | ---- | ---- |
| **分离导出** | 每个保留块单独输出为一个文件 | 目标目录 + 命名模板 |
| **合并坍缩** | 删除整行/整列后剩余单元紧贴拼接为一张图（坍缩不可行时该项禁用并给出原因） | 目标文件 |
| **合并重排** | 按显式序列把保留块填入新画布（**仅 L3 可用**） | 目标文件 |

其他参数：

- **格式**：PNG / JPEG / WebP / BMP。
- **质量**：有损格式（JPEG/WebP）的压缩质量。
- **命名模板**：仅分离导出，控制输出文件名。
- **导出前预览缩略图**：实时展示输出效果（合并模式按真实画布等比缩放、所见即所得；分离模式拼成缩略触图）。
- **导出时烧录标注**：勾选后标注合成进像素随切割落位。
- **重排专属**：列数/行数（0＝自动推导）、单元宽/高（0＝用保留块原尺寸）、填充色、填充顺序（行/列优先 + 蛇形 + 倒序）、「按格数自动」按钮；当 `cols×rows < 保留块数` 或单元尺寸 < 网格单元尺寸时给出内联红字警告 + 导出前弹窗二次确认。

## 9. 配置文件加载 / 保存

- **文件 → 保存配置…**：把当前作业参数（模式、切割、选择集、排序、导出参数）写为 §9 schema 的 JSON 文件。
- **文件 → 加载配置…**：读取 JSON 反向还原到界面；**加载本身可一步撤销**（入同一撤销栈）。
- 配置**不含图像像素**，仅保存参数态。

## 10. 常见问题（FAQ）

**Q：为什么旋转/缩放后我框选的选区消失了？**
A：旋转 90°/270° 或缩放会改变图像尺寸，基于旧尺寸的选区坐标失效，故被自动清除，请在新尺寸上重新框选。

**Q：Ctrl+Z 撤销不了刚才的预处理（旋转/反色）？**
A：预处理未纳入全局撤销（这是有意取舍）。请用「图像 → 重置预处理」还原为原图。

**Q：找不到「箭头」和「扇形」标注？**
A：当前版本底层尚未提供这两种形状类型，属已知限制。可用「直线 + 多线段」或「圆/椭圆」近似替代。

**Q：拖选区时想精确对齐图像中心/边缘？**
A：拖动时靠近图像边缘或中心会自动吸附（阈值默认 8px）。当前吸附目标为图像边缘与中心线；网格线吸附尚未接入。

**Q：「合并重排」为什么是灰的？**
A：重排为 L3 专属，仅在网格分割模式下可用；离开 L3 会自动复位为坍缩。

**Q：「合并坍缩」为什么被禁用？**
A：当前选择集不满足坍缩条件（并非删除完整的行/列），面板会给出不可行原因；此时请改用重排或分离导出。

**Q：导出很慢 / 界面卡顿？**
A：预览始终使用降采样副本（大图也流畅），只有导出时才对全分辨率运算。大图重采样期间会显示进度对话框，属正常现象。

## 11. 已知限制汇总

- 标注类型**不含箭头、扇形**（Core `ShapeType` 未提供）。
- **预处理不纳入 Ctrl+Z 全局撤销**，靠「重置预处理」回退。
- 坐标吸附目前仅支持**图像边缘 + 中心线**，**网格线吸附**尚未接入。
- 缩放/重采样未提供**插值方式下拉**（内部固定双线性）。
- 8000×8000 ≥30fps 的性能验证尚未正式落地（预览已采用降采样以满足设计目标）。
