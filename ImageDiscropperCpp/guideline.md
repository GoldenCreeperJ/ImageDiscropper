# 给 AI Agent 的任务说明书
> **任务目标**：依据《图像区域提取、反向剔除与网格分割工具 · 需求规格说明（终稿 v1.0）》，快速生成一个可运行的GUI，实现 MVP 范围内的完整功能。
>
> **使用方式**：本说明书是终稿的可执行化版本。Agent 应把本说明书当作**唯一的施工图**，终稿中未在此处明确的内容，以终稿为准；两者冲突时，以终稿为准。

## 🎯 项目核心哲学 (必须牢记)
常规裁剪只回答“保留哪一块”；本工具回答“**沿哪些线切开、留下哪些块、怎么重新拼起来**”。
所有功能必须基于统一的 **Grid-Selection-Emit 模型** 实现：
`原图 → ① 切割线集合 → ② 诱导网格 → ③ 选择集 → ④ 极性(Keep/Remove) → ⑤ 排布导出(Collapse/Rearrange)`。
**严禁**为 L1(标准提取)、L2(反向剔除)、L3(网格分割) 编写三套独立的裁剪逻辑，它们必须是同一引擎的不同参数预设。  
**公理不可违反**：切割线是贯穿全图的直线，不是线段。任何实现若把切割理解为“线段围成的框”，视为违反需求。

## ⚠️ 绝对工程规范 (Strict Rules - 违反即视为不合格)
1. **目录说明**：根目录必须有 `README.md` (含应用介绍、组成、终稿概念映射)。**每个子目录**必须包含 `README.md` 说明该目录作用。
2. **注释规范**：
    - **每个文件头部**必须包含注释
    - **每个函数首部**必须包含注释
    - **代码内部**：在复杂逻辑分块处，必须用中文注释注明。
3. **模块化拆分**：严禁“上帝文件”(God File)。代码必须按功能、任务严格分文件撰写。

## 2、功能实现清单

**前置说明**：Core（`ImageDiscropperCore`）已完成，是 C++17 静态库，命名空间 `idc`。CLI 已完成。GUI 采用 **Qt 6.x + Widgets + QGraphicsView**，与 Core 同语言、同进程、同构建系统，**零 FFI**。

**首先检查现有 Core，不要假设 Core API**：

1. 列出 Core 对外暴露的全部公开 API（头文件清单 + 函数签名）。
2. 列出 Core 的模式入口函数（extract / erase / grid 各自对应哪个函数）。
3. 列出 Core 的错误类型（`CoreError` 或等价类型）及其可区分的情形。
4. 列出 Core 的配置结构（对应终稿 §9 的 JSON 结构在 C++ 中的映射）。

若发现 Core 缺少 GUI 所需的某个接口（例如 GUI 需要读取当前导出块的尺寸），Agent **不得在 GUI 中补实现**，而应：

- 直接报告错误
- 在 GUI 代码中以 `// TODO(core): 需要 Core 提供 xxx` 标注。
- GUI 可能需要以下能力，若 Core 未提供，**在 Core 中补充**（而不是在 GUI 中补）：

| 能力               | 用途                     | 建议接口                                                    |
|------------------|------------------------|---------------------------------------------------------|
| 降采样预览图生成         | NFR-3，8000×8000 图像流畅交互 | `Image generatePreview(const Image&, int maxDimension)` |
| 保留块源区域查询         | 画布上绘制高亮遮罩              | 若 `Fragment` 已含源 `Rect`，无需补充                            |
| 当前选择集下的保留/删除单元列表 | 画布上区分"将被删除的单元"与"保留的单元" | `std::vector<Cell> resolveSelection(...)`               |
| 标注图层与预处理图像的合成 | 预处理后的图像作为标注的底图 | 若 `AnnotationLayer` 已支持绑定底图，无需补充 |


### 2.1 三层模式

| 层级 | 模式     | GUI 定位            |
|----|--------|-------------------|
| L1 | 标准提取模式 | 默认进入模式，降低首次使用门槛   |
| L2 | 反向剔除模式 | 核心特色，需专属入口与专属视觉反馈 |
| L3 | 网格分割模式 | 高级编排，提供完整参数与排序面板  |

### 2.2 统一引擎

```text
原图 → ① 切割线集合 → ② 诱导网格 → ③ 选择集 → ④ 极性 → ⑤ 排布导出
```

GUI 的参数面板就是这五个阶段的交互入口。

### 2.3 关键术语


- 切割线（cut line）：贯穿全图的水平/垂直直线。
- 带（band）：相邻两条同向切割线之间的整条区域。
- 单元格（cell）：一条竖带与一条横带的交集。
- 十字带：矩形选区诱导的"竖带 ∪ 横带"。
- 极性（polarity）：`keep` / `remove`。
- 坍缩（collapse）：删除整行/整列后剩余单元紧贴拼接。
- 重排（rearrange）：按显式序列填入新画布。

| ID     | 功能 | GUI 呈现                          |
|--------|----|---------------------------------|
| FR-1.1 | 旋转 | 90° 步进按钮 +  插值方式 + 背景填充 |
| FR-1.2 | 翻转 | 水平 / 垂直按钮                       |
| FR-1.3 | 标注 | 标注工具面板                  |

| FR-1.5 | 控制 | 撤销、重做、清除、预览、隐藏                  |

**支持的标注类型**：

- 矩形、正方形、菱形
- 圆形、椭圆、扇形
- 三角形、等腰三角形、等边三角形、直角三角形
- 直线、箭头、多线段
- 文字
- 画笔

**标注属性**：颜色、粗细、填充。

**标注的图层特性**：

- 独立图层，与底图分离。
- 可添加、删除、选择、编辑。
- 导出时可选是否烧录到像素。

**设计约束**：标注图层与切割操作解耦。切割时标注随像素一起被切开，而不是被单独处理。

├────────────┬──────────────────────────────────┬──────────────────────┤
│            │                                  │                      │
│  左侧面板   │        中央画布                   │   右侧面板            │
│            │        (QGraphicsView)            │                      │
│  - 模式切换 │                                  │  - 参数面板（随模式）  │
│  - 极性开关 │                                  │  - 选择集面板         │
│  - 工具选择 │                                  │  - 排序面板           │
│  - 图层列表 │                                  │  - 导出面板           │

**布局约束**：

- 左侧面板固定宽度（约 220px），右侧面板可折叠（约 300px）。

- 右侧面板使用 `QTabWidget` 或 `QToolBox` 分组，避免面板过长。

### 4.2 画布区（QGraphicsView + QGraphicsScene）

**必须实现**：

| 交互        | 实现方式                                               |
|-----------|----------------------------------------------------|
| 显示原图      | `QGraphicsPixmapItem`，使用 Core 的降采样预览图（NFR-3）       |
| 显示预处理结果 | 预处理执行后，画布显示新的底图 |
| 显示标注 | 标注图元作为独立 `QGraphicsItem` 叠加在底图上 |
| 缩放        | 滚轮缩放 + 工具栏缩放按钮 + 快捷键（Ctrl + `+` / `-` / `0`）       |
| 平移        | 空格 + 拖拽，或中键拖拽                                      |
| 显示切割线     | `QGraphicsLineItem`，贯穿全图                           |
| 拖拽矩形生成切割线 | `QGraphicsRectItem`，拖拽生成切割线，VBand/HBand/十字带由当前模式决定 |
| 拖拽切割线     | `ItemIsMovable` + `itemChange` 事件，实时更新参数面板         |
| 拖拽切割线焦点   | `ItemIsMovable` + `itemChange` 事件，实时更新参数面板         |
| 显示网格      | L3 模式下，由 Core 的 `induceGrid` 结果绘制网格线               |
| 显示选区      | 矩形选区用 `QGraphicsRectItem`，半透明填充                    |
| 显示保留/删除预览 | 保留块高亮为绿色半透明，删除块高亮为红色半透明（L2 反向剔除模式下必须明显）            |
| 显示单元格编号   | L3 自定义排序模式下，每个单元格角标显示序号                            |
| 键盘微调      | 方向键 ±1px，Shift + 方向键 ±10px                         |
| 坐标吸附      | 图像边缘、网格线、中心线；吸附阈值可配置（默认 8px）                       |
| 右键菜单      | 清除切割线、重置视图、切换预览                                    |

**图层顺序（z-order，从下到上）** ：

1. 底图（预处理后的图像）
2. 标注图层（标注图元）
3. 保留块遮罩（绿色）
4. 删除块遮罩（红色）
5. 网格线
6. 切割线
7. 选区边框
8. 单元格编号

**性能约束（NFR-3）** ：

- 画布显示的是降采样副本，不是原图。
- 拖拽切割线时，只更新切割线与遮罩，不重新渲染整个图像。
- 8000×8000 图像预览交互 ≥ 30 fps。

**视觉规范**：

- 切割线：蓝色实线，2px，带拖拽手柄。
- 切割点：蓝色实心圆，3px。
- 网格线：灰色虚线，1px。
- 保留块遮罩：绿色 `rgba(0, 200, 0, 60)`。
- 删除块遮罩：红色 `rgba(200, 0, 0, 60)`。
- 选区边框：橙色实线，2px。
- 单元格编号：白色背景黑字，或黑色背景白字（依底色对比自动选择）。
- 标注图元：使用用户设置的颜色与粗细；选中时显示控制点。

### 4.3 模式切换

顶部工具栏提供模式切换，三个按钮或下拉菜单：

- **标准提取（L1）** ：默认进入模式。
- **反向剔除（L2）** ：核心特色，按钮颜色与其他两个不同（如强调色）。
- **网格分割（L3）** ：高级模式。

**模式切换行为**：

- 切换模式时，右侧参数面板切换为对应模式的参数。
- 画布上的切割线与选区**保留**，但预览呈现方式随模式变化。
- 提供「**转为网格模式编辑**」入口：在 L2 画完选框后，一键把当前诱导网格送进 L3 继续精修（终稿 §4.4.3）。

### 4.4 极性开关

- 位置：左侧面板顶部，或工具栏。
- 形式：两个互斥按钮或一个开关。
- 视觉：
    - `keep`（保留框内）：绿色。
    - `remove`（删除框内）：红色。
- 行为：切换后**实时**更新画布预览（NFR-6）。

| 导出前预览   | 显示最终结果的缩略图                           |

**约束**：

- 分离导出使用 `QFileDialog::getExistingDirectory`。
- 合并导出使用 `QFileDialog::getSaveFileName`。
- 导出前必须调用 Core 的坍缩可行性判定，不可行时禁用坍缩选项。

### 4.7 撤销 / 重做

- 复用 Core 的 `HistoryManager<T>`。
- 撤销 / 重做覆盖：切割线变更、选区变更、排序变更、极性切换、网格参数变更、预处理操作、标注增删改。

### 4.8 配置文件

## 5. UI / UX 设计原则

### 5.1 视觉设计

- **配色**：中性灰背景，画布区深灰，面板浅灰。强调色用于当前模式与极性。
- **字体**：系统默认，中文优先，避免使用衬线字体。
- **图标**：使用 Qt 内置图标或开源图标集（如 Feather Icons），保持风格统一。
- **间距**：面板内边距 8px，控件间距 6px，分组间距 12px。
- **圆角**：按钮 4px，面板 6px。

### 5.2 交互设计

- **即时反馈**：所有交互必须在 100ms 内给出视觉反馈。
- **可撤销**：任何状态变更都可撤销。
- **无阻塞**：大图处理时显示进度指示，不冻结 UI。
- **错误提示**：错误用非模态提示（如状态栏或 Toast），不用模态对话框打断用户。
- **首次使用**：首次进入时显示简短引导，说明三种模式的区别。

### 5.3 L2 反向剔除的专属视觉

L2 是产品核心特色，必须给它专属视觉反馈：

- 用户框选矩形后，画布上**立即**显示：
    - 贯穿全图的切割线（蓝色实线）。
    - 被删除的十字带（红色半透明遮罩）。
    - 保留的四角（绿色半透明遮罩）。
- 拖拽切割线时，遮罩实时更新。
- 极性切换时，遮罩颜色与位置即时切换。

**这是让用户"看懂"反向剔除的关键（NFR-6）。**

### 5.4 帮助与引导

- 菜单「帮助 → 使用说明」打开帮助文档。
- 每个参数控件提供工具提示（Tooltip），说明其含义与取值范围。
- 模式切换按钮提供工具提示，用一句话说明该模式的价值。
