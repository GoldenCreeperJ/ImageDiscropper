# src

**目录作用**：CLI 层的实现代码（除各子命令外的公共部分）。承载「顶层编排 + 参数解析 + 值解析 +
错误报告 + 帮助文本 + 执行桥 + main 入口」。子命令实现另见 `src/commands/`。

**分块依据**：一个关注点一个 `.cpp`（严禁上帝文件）。CLI 是薄壳——本目录
所有文件只负责「解析 / 编排 / 格式化 / 退出码」，不含任何切割 / 几何 / 排序 / 极性 / 合成 / 编解码逻辑，
后者全部委托 Core。

| 文件                    | 职责                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
|-----------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `main.cpp`            | 程序入口：把 `argv`（去程序名）转发给 `cliMain`，返回其退出码                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `cli_app.cpp`         | 顶层编排 `cliMain`：**装配译文表 → 先按环境变量链定语言（让 `--version` / 顶层 `--help` 也本地化）→ 全局选项 → 再按 `--lang` 覆盖（认不出则报因取退出码 1）→ help/version → 定位子命令 → 分派 → 未捕获异常兜底(5)                                                                                                                                                                                                                                                                                                            |
| `arg_parser.cpp`      | `ArgParser::parse`（token 归类）+ `parseGlobalOptions`（全局选项扫描，含 `--bundle-assets`）                                                                                                                                                                                                                                                                                                                                                                                |
| `value_parser.cpp`    | 「字符串 → 类型」纯转换与格式校验（严格整数解析、十六进制颜色、枚举、命名模板、有损质量 0~100）                                                                                                                                                                                                                                                                                                                                                                                                          |
| `cli_error.cpp`       | `reportError` / `makeError`：按三段式格式写 stderr                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `i18n/`（子目录）          | i18n 门面的本层实现 `cli_i18n.cpp`（`applyLanguage()` 语言来源优先级 + 环境变量链）与英文译文表 `lang_en.cpp`（msg 半 + `installCatalogs()`）/ `lang_en_help.cpp`（help 半 + `installHelpCatalog()`）见 [`src/i18n/`](i18n/README.md)，逐文件职责见该目录说明                                                                                                                                                                                                                                               |
| `help.cpp`            | 帮助文本输出全集（单文件）：顶层帮助 / 版本 / 子命令分派 + `new/extract/erase/grid/config` 五个子命令帮助 + 共享小节（标注段 / 图案矩阵 / 生成源段）+ 列宽的编译期推导（`constexpr optWidth` 按不可译 `kUse*` 串长取 max）；文本本体全在 `include/i18n/cli_texts.h::help`，每个 `helpXxx()` 只决定输出顺序；版本来自编译期宏 `IDC_CLI_VERSION` / `IDC_CORE_VERSION`                                                                                                                                                                                       |
| `job.cpp`             | 执行桥：（带 `layers` 时）`buildLayerCanvas` 以已解析底图 base 为基、逐层解码叠加 File 源图（相对配置目录 / `<配置名>.assets`，越界拒绝）注入→`canvas::composeCanvas(layers,w,h,base)` 先铺全透明底、依底图 base→叠加层（按 zOrder）展平为工作图（画布无级背景） → `runEngine` → 坠缩校验 → `exportImage` → 退出码映射（三层命令 + config 共用）；`buildBaseCanvas` 据 `config.base`（§7 `generate` 段同构底图）将 File 底按相对名解码注入 / Recipe 底现算后 `canvas::composeBase` 展平为底图；先物化 preprocess 后烧标注（标注不受画布预处理影响）；`bundleLayerAssets` 实现 `--bundle-assets`（相对名复制、越界拒绝） |
| `annotation_args.cpp` | 命令行标注收集：`hasAnnotationOptions` / `collectAnnotations`（内联对象 + 根数组文件，可重复、累积追加）+ 本地 `readFileText`；解析委托 Core `parseAnnotationsFromJsonText`，本文件不自行解析 JSON                                                                                                                                                                                                                                                                                                        |
| `generate_args.cpp`   | 命令行图像生成装配：`hasGenerateOptions` / `buildGeneratedImage`（尺寸/图案名/方向/颜色/周期的格式校验 + 委托 Core `generate::makePattern`）/ `resolveInputImage`（`--input` 读文件 或 生成画布）；颜色解析复用 `value_parser::parseColor`，本文件不实现像素逻辑                                                                                                                                                                                                                                                        |
| `commands/`           | 一命令一文件：`extract` / `erase` / `grid` / `config` / `new`（见该目录 README）                                                                                                                                                                                                                                                                                                                                                                                           |

**关键约定**：
- 常量层引用：选项名 / 命令名 / 报错文案一律取 `cli_texts.h`（别名 `opts` / `cmds` / `msgs`），不在本目录重新写字面量；
  面向人的 `msg` / `help` 经 `IDC_CTR(分组, 常量名)` 取译文（源语言 zh-CN 不建表 → 逐字节回退常量层原文）；
  帮助输出的等值性由「逐字节比对 `--help` 全文」验收，而非目测。
- 参数校验顺序严格遵循（命令存在 → 全局选项 → 必填 → 互斥 → 格式 → 输入可读 → 调 Core），
  前 5 步在调用 Core 之前完成，失败一律退出码 1。
- `runEngine` 仅在 L3 遇到「MERGED+COLLAPSE 但不可坍缩」时自动改用 REARRANGE 并返回 `ok=true, collapsible=false`
  （L1/L2 直接报错，SPEC §4.3）；CLI 据 `JobOptions::explicitCollapse` 决定是否显式报错为退出码 2。
