# tests —— Core 自测入口

**目录作用**：极简自测入口，用于验证核心模块与 Grid-Selection-Emit 引擎的正确性。
不依赖任何第三方测试框架（如 GoogleTest），只用断言宏（`CHECK` / `CHECK_MSG`）+ 标准输出。

**分块依据**：`test_main.cpp` 的 `main()` 统一调用各测试段；断言宏与跨文件测试段声明抽到
`test_harness.h` 共享；引擎验收测试按主题拆为 pipeline / export / boundary / config-json 四个独立 `.cpp`，
i18n 拆为机制内核与目录对账两个独立 `.cpp`，由 CMake 统一收集，避免把所有测试塞进单一 God File（严禁 God File）。

| 文件                            | 职责                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|-------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `test_harness.h`              | 共享的 `CHECK` 断言宏与 `CHECK_MSG`（带自定义说明的变体，供对账类测试把失败原因一次打到行尾）+ 六个引擎测试段（`testEnginePipeline` / `Export` / `Boundary` / `ConfigJson` / `AnnoParseText` / `AnnoAnchorRoundTrip`）与两个 i18n 段声明                                                                                                                                                                                                                                                                                                                                            |
| `test_main.cpp`               | `main()` 入口：core（图像读写与格式转换）/ geometry（命中检测、包围盒、圆角倒角）/ pixel_kernels（`applyOne` 逐像素核：灰度、旋转、翻转、缩放、通道反色/分离、灰度无损回归）/ annotation（ShapeFactory / Rasterizer / AnnotationSet / ViewTransform + 跨模块直编的 GUI `AnnotationEditor` 会话态）/ preprocess（流水线按序执行 + `applyExec` 与逐步 `apply` 逐像素等价回归 + 种子随机性质测试）/ preprocess_session（GUI 零 Qt 预处理会话，跨模块直编：不变式 / 归一化 / baseDirty / 签名）/ history（泛型撤销栈 `core::HistoryManager<T>`）/ pipeline（泛型有序步骤队列 `core::Pipeline<T>` 的按序增删移改与越界钳制/忽略边界策略）/ engine 数据结构冒烟测试 / generate / canvas + 调用六个引擎验收段与两段 i18n |
| `test_i18n_core.cpp`          | i18n 机制内核（零 Qt）：表登记与同语言累加 / 重复键先登记者胜、语言码归一（大小写与地区后缀）、**未装语言与缺键必回退源值（永不空串）**、`formatPattern` 的 `%N` 按编号替换 / 越界与孤立 `%` 原样保留                                                                                                                                                                                                                                                                                                                                                                                                        |
| `test_i18n_catalog.cpp`       | **i18n 目录对账**（零 Qt）：用 CMake 注入的 `IDC_TEXTS_SOURCE_ROOT` 直读三层常量层与三张译文表，行级命名空间栈解析出 `(分组, 常量名)` 键集，断言无孤儿键 / 无层内重复键 / 无跨层撞键 / 契约组不越界 / 译文与源值 `%N` 占位符集合一致，并打印各组覆盖率（未译不 fail，允许逐批补全）                                                                                                                                                                                                                                                                                                                                                  |
| `test_engine_pipeline.cpp`    | 功能：Standard 十字/横线/竖线保留尺寸；Erase 四角位置与坍缩尺寸；极性开关；Grid 网格/单元选择/排序（row·col-major·reverse·snake·custom）/重排填充顺序 MergeOrder /「仅 Grid 可重排」限制 + 仅尺寸入口与图像入口的等价性                                                                                                                                                                                                                                                                                                                                                                             |
| `test_engine_export.cpp`      | 导出：分离导出写入文件夹（自动创建）与命名模板、坍缩合并尺寸、坍缩不可行→降级重排、PNG/BMP/JPEG/WebP 四格式写盘成功                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `test_engine_boundary.cpp`    | SPEC §5 边界：E-1~E-8 全覆盖 + 空块跳过 + 像素归属无重复无丢失（左闭右开校验）                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `test_engine_config_json.cpp` | SPEC §7 配置 JSON 往返：四类标注（多边形/椭圆/路径/文字）含样式与变换快照逐字段比对、`annotations` 段缺失向后兼容、缺段+传层＝清空（配置为真相源）、layers/base/opacity 段往返与旧配置兼容；`testAnnoParseText`（`parseAnnotationsFromJsonText` 文本段级解析：单对象/根数组/累积/回滚/逐条强制校验负例/空串，供 CLI 复用）；`testAnnoAnchorRoundTrip`（约束多边形 8 例顶点级 + 圆/椭圆 3 例包围盒级锚点往返一致）                                                                                                                                                                                                                                               |

> 导出类测试写入临时目录并校验文件存在 / 尺寸 / 文件夹内图片数，测试结束后清理。
> `test_main.cpp` 经跨模块直编把 GUI 的 `annotation_editor.cpp` / `preprocess_session.cpp`（零 Qt 会话半边）一并编入 unit_tests，回归其无头侧成立的会话语义。

## 运行

```bash
cmake -S .. -B ../build
cmake --build ../build --target unit_tests
../build/unit_tests          # 或经 CTest：ctest --test-dir ../build
```
