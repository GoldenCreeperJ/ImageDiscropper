# include/io

**目录作用**：基础图像 I/O 能力的对外接口——图像编解码与文件读写（SPEC §4.5）。
从合成/导出逻辑中隔离出来，与 [`core/path_utf8.h`](../core/path_utf8.h) 平级：前者管路径、本模块管像素编解码。

**分块依据**：编解码是唯一对外接口，单文件承载；具体编解码器与第三方库封装在 `src/io`，本公共头不暴露类型。

| 文件           | 概念 / 阶段              | 主要内容（声明）                                                                                                                       |
|--------------|----------------------|--------------------------------------------------------------------------------------------------------------------------------|
| `image_io.h` | 图像编解码 I/O（SPEC §4.5） | `readImageFile`（解码为 RGBA）/ `writeImageFile` / `encodeImageToMemory`（PNG/JPEG/BMP/WebP）。`path` 按 UTF-8 解析，绕开 Windows ANSI 码页限制。 |
