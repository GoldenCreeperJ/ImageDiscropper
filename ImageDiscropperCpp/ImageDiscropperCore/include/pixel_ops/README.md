# include/pixel_ops

**目录作用**：像素级处理算法，作用于 `core::Image`。对应终稿 FR-1「基础图像处理」中
在切割之前执行的调整能力（FR-1.1 旋转、FR-1.2 翻转、FR-1.4 调整）。

**分块依据**：按算法性质拆分为「颜色/通道」与「几何变换」两类，各自独立成文件，
互不依赖，便于单独测试与复用。

| 文件                | 职责                                  |
|-------------------|-------------------------------------|
| `color_ops.h`     | 灰度化、按通道反色、按通道分离、颜色拾取（`pickColor`）   |
| `geometric_ops.h` | 90° 系列旋转、水平 / 垂直翻转、最近邻 / 双线性缩放与尺寸调整 |

> 说明：本目录只提供**无状态算法函数**（输入图像 → 输出新图像，不修改入参）；
> 步骤化编排由 `preprocess` 模块负责。
