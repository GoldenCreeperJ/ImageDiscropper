# src/core

**目录作用**：`include/core` 下头文件的实现代码集合。

**分块依据**：与头文件一一对应，每个 `.cpp` 只实现同名头文件里声明的接口，
避免出现"一个 cpp 实现所有功能"的耦合。

| 文件          | 职责                   |
|-------------|----------------------|
| `color.cpp` | 颜色运算与 RGB ↔ HSV 转换实现 |
| `point.cpp` | 距离计算等辅助函数            |
| `image.cpp` | 图像像素缓冲、读写、格式转换实现     |
