# include/history

**目录作用**：通用的撤销 / 重做栈，服务于终稿 FR-1.5「撤销、重做」与 NFR-4「全流程可逆」。
以模板形式提供，可承载任意类型的历史条目（标注记录、预处理步骤、引擎配置等）。

**分块依据**：撤销重做是与业务无关的通用能力，独立成一个模板头文件；
模板实现直接内联在头文件中，避免额外的显式实例化文件。

| 文件 | 职责 |
|---|---|
| `history_manager.h` | 泛型撤销 / 重做栈 `HistoryManager<T>`：`push` / `popToRedo` / `popFromRedo` 等 |

> 语义：`push` 追加新条目并清空重做栈（新操作切断「未来」）；`popToRedo` 撤销、
> `popFromRedo` 重做。
