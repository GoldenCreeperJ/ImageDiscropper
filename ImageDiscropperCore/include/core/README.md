# include/core

**目录作用**：定义整个库最底层、无外部依赖的基础数据类型。所有上层模块
（`geometry` / `pixel_ops` / `annotation` / `preprocess` / `history` / `engine`）
都直接或间接依赖这里的类型。对应终稿 §10.2 的 `Image` 概念。

**分块依据**：将「数据」与「算法」解耦，把最基础的像素点、颜色、图像三种数据结构
独立成三个头文件，避免上层出现循环依赖。

| 文件 | 职责 |
|---|---|
| `color.h` | RGBA 颜色结构体 `Color` 及颜色运算（反色 / 感知反色 / 互补色 / HSV 转换） |
| `point.h` | 二维浮点坐标 `Point2D`、整数点 `Point2I` 及其算术运算 |
| `image.h` | 图像像素容器 `Image`，支持 RGB / RGBA / GRAY 三种模式，行主序存储 |

> 坐标与像素约定遵循终稿 §3.1：整数像素、原点左上、`x` 向右 `y` 向下。
