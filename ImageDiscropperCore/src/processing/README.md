# src/processing

**目录作用**：`include/processing` 下头文件的实现代码。

**分块依据**：每个 `.cpp` 只实现同名头文件里声明的算法，保持"一个功能一个文件"，
方便未来独立替换、单元测试或并行编译。

| 文件                  | 职责                       |
|---------------------|--------------------------|
| `color_ops.cpp`     | 灰度化 / 通道反色 / 通道分离 / 颜色拾取 |
| `geometric_ops.cpp` | 90° 系列旋转、翻转、最近邻 / 双线性缩放  |
